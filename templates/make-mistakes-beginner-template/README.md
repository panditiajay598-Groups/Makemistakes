# MakeMistakes Beginner Project

This workspace is created automatically for your problem.

## Already included

- Node.js runtime (inside BuildOS)
- Next.js + React + TypeScript
- Tailwind CSS, Lucide icons, Framer Motion
- Three.js + React Three Fiber + Drei

## How to work

1. Open files on the left
2. Edit code in the editor
3. Click **Run**
4. Click **Preview**

You do not need to install packages on your laptop.
