# MakeMistakes Intermediate Project

Isolated BuildOS workspace for Intermediate problem statements.

## Pre-installed (automatic)

**Core:** Node.js, Next.js, React, TypeScript  
**UI / 3D:** Tailwind, Lucide, Framer Motion, Three.js, R3F, Drei  

**Intermediate extras:**
- `zod` — validation schemas
- `zustand` — client state
- `@tanstack/react-query` — async data
- `recharts` — charts
- `date-fns` — dates
- `clsx` — class names

You do not run `npm install` on your device. BuildOS prepares this workspace for you.
